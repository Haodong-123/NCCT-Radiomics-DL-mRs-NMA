# Supplementary material and analysis code

**NCCT-Based Radiomics and Deep Learning for mRS Prognostication After Spontaneous Intracerebral Hemorrhage: A Network Meta-Analysis**

This repository contains the supplementary material and the analysis code for the manuscript above.

## Contents

- `analysis_code.zip` — R scripts (and input data) for the Bayesian network meta-analysis of prognostic classification performance and for the meta-regression analyses


## Notes

- No primary patient data are included; all analyses are based on aggregate, study-level data extracted from published studies.
- Analyses were performed in R (version 4.3.2) with JAGS (version 4.3.1).
